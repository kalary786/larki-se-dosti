# Larki Se Dosti

Android app built with Kotlin and Jetpack Compose. Dark theme is the default. Light theme is available from My Profile.

Package: `com.kalary.larkisedosti`. Minimum SDK 26. The UI uses local sample data only.

## Build

```bash
./gradlew assembleDebug
```

Open the project in Android Studio, or point `local.properties` at your Android SDK:

```
sdk.dir=/path/to/Android/sdk
```

## Web pages

Static pages live in `web/`: home, privacy policy, support (`support@larkisedosti.app`), account deletion, and child safety standards. The app links to the same copy from Account & Privacy and Help & Support.
